# くるっくー

**家族の知らせと日々を届ける鳩。**

認知症の父と暮らす家族のための、電子伝書鳩のWebアプリです。Built with Claude: Japan 2026（2026年11月2日〜8日）の期間中に作りました。

- アプリ：https://tuesdayghost.github.io/kurukku/
- デモ動画（3分以内）：https://youtu.be/Hh3njk2oaDI

## 誰の、どんな課題を、どう解決するか

**誰の**：認知症の父と、一緒に暮らす家族（企画者の葵依の家）。

**どんな課題**
- 毎朝、小さなホワイトボードに日付・天気・気温・父と家族の予定を書いていました。調べて書く3〜4分が朝食の時間を削り、上に新聞を置かれると文字が消えて書き直し。父は何度も「今日は何日？」「誰がどこにいる？」と確かめます。
- 「忘れることそのものより、周りの反応がつらいんじゃないか」と思っています。
- 以前、父が外出先から戻らなかったとき、最近の顔写真も正確な身長もすぐには出せませんでした。顔写真は、デイでもらったプリントがたまたまあっただけでした。

**どう解決するか**
- 父の部屋のタブレットに、**日付・曜日・天気・時計・今日の予定・家族の知らせ**を、大きな文字でいつも同じ場所に出します。父は操作しなくてよく、何度見ても同じ答えがあります。
- 予定の時間になると、鳩が鳴いて「くるっくー。はとやまです。お父さん、6時半から夕ごはんです。」と読み上げ、知らせの画面に切り替わります。終わると静かに元に戻ります。
- 家族はスマホから予定や「12時に戻ります」のような知らせを入れるだけ。毎朝書き直す必要がなくなります。
- **レスキューカード**：父が戻らないとき、家族はボタン1つで、顔写真・身長・体重・靴のサイズ・よく着る服をまとめたカードを出せます。見せる・電話で読み上げる・1枚の画像と文字で送る、のどれにも使えます。
- **鳩月報**：ひと月にくるっくーが運んだ記録から、Claude がスポーツ新聞風の見出しと記事を書きます。家族が日記を書かなくても、その月の小さな出来事が残ります。

目指しているのは「忘れても大丈夫」と感じられる環境と、家族が息をつく5分の余裕（5 Minutes to Breathe）です。治療・認知機能の改善・不安の軽減を主張するものではありません。安心感や時間の短縮は、まだ測っていない「目指す価値」です。

## 画面と機能

| 画面 | 使う人 | できること |
| --- | --- | --- |
| 本人用の表示（父の部屋のタブレット） | 父。見るだけ | 日付・曜日・天気・時計・今日の予定・家族の知らせ。時間帯の知らせ（音・読み上げ・止める手段）。夜は暗い画面で時計と「今は夜です」。右下の鳩にさわると、意味のない優しい鳴き声で返事 |
| 居間（Yoga 3） | 家族 | 表示に加えて、予定を簡単に追加。操作しないと予告のあと表示に戻る |
| 家族のスマホ | 家族 | 予定の追加・変更（「この日だけ」と「この日から先」を分ける）・中止、知らせ、ひとこと・写真、鳩月報、レスキューカード、端末の登録と設定 |

父の部屋・居間・家族で**役割ごとに書き込みの権限を分けて**います。父の部屋の端末は、画面のボタンを隠すだけでなく、データベースの側で書き込みを止めています。レスキューカードと写真は、家族の役割の人だけが見られます。

## Claude をどう使ったか

### 開発：Claude Code が開発の中心
企画者はプログラミングをほぼしたことがありません。すべてのコード・データベース・テストを、Claude Code（Claude Opus 5.5）との会話で作りました。

- **仕様 → 作業リスト → 決定ログ**：事前に書いた企画書（`docs/spec.md`）をキックオフ後に取り込み、Claude Code が「目的・最初に動かす範囲・実機の懸念・質問」を返すところから始めました。仕様が変わるたびに、`docs/spec.md` と `docs/tasks.md`（未実装・仮実装・実機確認済の区別と、理由つきの決定ログ）を更新しています。
- **実機での一往復を早く**：初日に音・読み上げ・画面点灯のテストページを作り、Androidタブレット・iPad・Windowsで確かめてから本体を作りました。
- **MCP で Supabase を操作**：テーブル・行レベルセキュリティ・関数の作成を、Supabase の MCP サーバーから行いました。「父の部屋の端末からは本人情報が見えない」「居間からは他人の予定を変えられない」「同じ通知を二重に数えない」などを、一時的なアカウントでSQLのテストとして確かめ、取り消しています。
- **偽の接続先でブラウザを動かして確認**：作業環境から本番のサーバーに直接つなげないため、Playwright で偽の接続先を差し込み、画面の見た目・時刻の早送り・操作の流れを確かめてから、実機で葵依が確認しました。
- **Skill**：UI の判断の根拠として、`kurukku-ui-review`（WCAG 2.2／JIS X 8341-3／W3C COGA をもとに、規格の要件・推奨・仮説・好みを区別する）を別の Claude と作り、`.claude/skills/` に入れて使いました。音を止める手段（SC 1.4.2）や居間の予告（SC 2.2.1）は、このSkillのレビューから実装しています。記録は `references/baseline-*.md`。
- **インタビュー**：別の Claude が葵依にインタビューし、実体験から仕様を決めました（家族の声やクローン音声は使わない、よく着る服を事前に登録する、など）。記録は [docs/interview.md](docs/interview.md)（仕様のインタビュー、プロジェクトについて、提出の朝の振り返り）。

### アプリの中：鳩月報の見出しと記事
- Supabase の Edge Function から Claude（`claude-opus-5-5`）を呼び、決まったJSONの形（structured outputs）で見出し・副見出し・記事を受け取ります（`supabase/functions/gazette/`）。
- **数字はデータベースのコードで数え、Claude には推測させません。** 予定は「予定○回」として書き、出かけた実績のようには書きません。本人をからかわない、病気や介護の効果に触れない、書かれていない出来事を作らない、と指示しています。
- 本人情報やレスキューカードの内容は Claude に渡しません。APIキーはサーバー側だけにあります。
- 鳩月報を作れるのは、許可した家だけ・月20回までです。許可と回数はデータベースの利用者からは書き換えられない場所にあり、Claude を呼ぶ前にサーバー側で確かめます（新規登録した知らない人に API の費用を使われないように。11/6 外部レビューで追加）。
- 応答を断られたときは、サーバー側で推奨のモデルに切り替えます（`fallbacks: "default"`）。

## 安全と個人情報

- 家族だけがデータを読み書きできます（Supabase の行レベルセキュリティ）。父の部屋の端末は見るだけです。
- 本人情報・写真・実在の家族のデータは、このリポジトリに入れていません。
- デモ動画とデモ用の家「豆田家」のデータは**すべて架空**です（`supabase/seed/`）。10月のデイの行事だけは、父が実際に参加した行事の種類（芋煮会と運動会、床屋）をもとにしたサンプルで、施設名や実際の日付は含めていません。画面には「デモ用データ（架空）」と出ます。

## 確かめたこと・まだのこと

- 実機で確認済み：父の部屋（Androidタブレット）・居間（Windows）・家族（iPhone）での予定の同期、時間帯の知らせと音・読み上げ・終了での復帰、天気、夜の表示、レスキューカード、鳩月報の生成、家族の画面の操作。
- 自動テスト：予定の計算・天気・レスキューカードの文字・鳩月報のタイルと材料・鳩月報を作ってよい家かの確認（`node --test tests/*.test.mjs tests/*.test.ts`）。レスキューカードの共有画像は、ブラウザで描いて目で確かめる（`tests/browser/rescue-card-image.mjs`、Playwright が要る）。データベースの権限と集計は SQL で確認。
- まだ：父本人の様子での確認、長い期間の使い勝手。規格（WCAG）への適合は表明していません（設計とレビューの根拠として使っています）。

## 構成と動かし方

- ブラウザで開く静的なWebアプリ（`app/`、ビルド不要）＋ Supabase（データ・ログイン・端末間の同期・写真・Edge Function）
- データベースの定義：`supabase/migrations/`、鳩月報の関数：`supabase/functions/gazette/`
- 主な資料：[仕様書](docs/spec.md)／[作業リストと決定ログ](docs/tasks.md)／[ロゴ](docs/brand.md)／[アプリ固定の手順](docs/guide-app-pinning.md)／[デモ動画の台本](docs/demo-script.md)

## 使っている素材・ライブラリ

- アイコン：[Lucide Icons](https://lucide.dev/)（lucide-static v1.60.0、ISC License）。使うアイコンの形だけを `app/icons.js` に入れている（ライセンス全文もファイル内）
- お知らせの音（鳩時計・振り子時計）：企画者が Python で作成。出典は [app/sounds/README.md](app/sounds/README.md)
- ロゴ・鳩：企画者が Claude と作成（[docs/brand.md](docs/brand.md)）
- デモ用のレスキューカードの顔と服の画像（架空の人物「豆田鳩蔵」）：企画者が Google Flow で作成（利用規約を確認済み）。アプリの保存場所（デモ用の家）にだけ置き、このリポジトリには入れていない
- デモ動画の BGM・効果音（鳩月報のファンファーレなど）：Claude がコードで合成（Python・ffmpeg で倍音つきの正弦波にエンベロープを掛けたもの）。既存の楽曲やフリー素材は使っていない。サムネイルも、架空のデータのアプリ画面から Claude が作成（`tools/demo-video/inserts/thumb.html`）
- 天気：[Open-Meteo.com](https://open-meteo.com/)（CC BY 4.0）
- データ・ログイン・同期：[Supabase](https://supabase.com/)（supabase-js v2.45.4、MIT License）
- 書体：Zen Kaku Gothic New（Google Fonts、SIL Open Font License）
