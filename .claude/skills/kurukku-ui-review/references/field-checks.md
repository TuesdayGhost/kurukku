# 資料だけでは決まらず、実機・本人で確かめること（候補集）

## 使い方
- **これは候補集。毎回全部やらない。** 1回のレビューで頼むのは、今回の変更に関係する2〜3項目まで（SKILL 8章）。
- 区別して書く:
  - **［実機］** 作り手や家族が端末で確かめる。父は関わらない。
  - **［観察］** 父の普段の暮らしの中で、様子を見るだけ。何かを頼まない。
  - **［任意］** 父に短く頼む確認。父が嫌がらない・疲れていないときだけ。断られたらやめ、また頼まない。
- 原則: 父を「検査」しない。本人が嫌がることはしない（[G] COGA 5.3）。記録は「何を見たか」を事実で書き、解釈は分けて書く。

## 本人用表示
- [ ] ［観察］普段の位置で、画面を見たあと迷わず予定のほうへ目が行っているか。近づいたり目を細めたりしていないか
- [ ] ［観察］数時間後にもう一度見たとき、同じ場所を見ているか
- [ ] ［観察］画面に触るか。触ったとき何を期待している様子か（ボタンに見える物がないか）
- [ ] ［観察］通知画面に切り替わったとき、驚いたり不安そうにしたりしないか。戻ったとき戸惑わないか
- [ ] ［観察］予定が変わって画面が更新されたとき、驚かないか
- [ ] ［観察］夜中に起きたとき、夜表示を見て落ち着いているか、まぶしそうでないか
- [ ] ［観察］振り子時計の音のあと、時刻を取り違えたような言動がないか（spec 3章 未決）
- [ ] ［任意］「今日は何曜日？」などとは聞かない。父が自分から画面の日付や予定を口にするかを見る程度にとどめる
- [ ] ［実機］チャイム＋読み上げの合計秒数（1.4.2 の3秒）。止める手段を入れたら、チャイムと読み上げの両方が止まるか
- [ ] ［実機］予定がいちばん多い日のデータで、全件が見えているか。読める下限の実寸を下回っていないか
- [ ] ［実機］朝・昼・夜の照明（逆光、映り込み）で、作り手が父の位置から見て読めるか
- [ ] ［実機］端末メニューの5秒長押しが、普通に触っていて偶然開かないか
