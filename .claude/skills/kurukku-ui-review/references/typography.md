# 日本語の文字組みと、活版の美しさ・懐かしさの両立

基本の考え方: 活版の文字組みの原則は「美しさ」だけでなく、**読みやすさのために磨かれてきた技法**でもある。
アクセシビリティと衝突するのは原則そのものより、「小さく・細く・淡く・詰める」という**紙の上の再現の仕方**であることが多い。
したがって、原則（比率・リズム・秩序）は残し、再現の仕方（サイズ・濃さ・コントラスト）を画面と読み手に合わせて変える。

## 1. 残すもの（原則）と変えるもの（再現）

| 活版・和文組版の原則 | 残し方 | 変えるもの | ラベル |
|---|---|---|---|
| 版面（はんめん）を決め、余白に秩序を持たせる | 画面ごとにグリッドと基本単位（文字サイズの倍数）を決める | 余白の絶対量は大きめに | [G] JLReq 版面設計／[P] |
| 基本文字サイズを全体の単位にする（字詰め・行送りを文字サイズの倍数で） | CSS で `--em` 単位の設計を続ける。数値を計算して決める作法はそのまま使える | 基本サイズ自体を視距離から決める | [P]／[H] |
| ベタ組み（字間を詰めない） | 和文本文はベタ組み。プロポーショナル詰めは見出しのみ | 本文の字間を詰めない | [G] JLReq／[H] |
| 行送りに十分な行間 | 本文の行送りは 1.5 以上を目安。長文でない表示画面は 1.4〜1.6 で実機確認 | 紙の 1.75 前後より狭める必要はない | [R+]候補 1.4.8／[G] JLReq（数値は要原文確認） |
| 行長を一定範囲に収める | 1行の字数を制限（1.4.8 は CJK で40字以下） | スマホでは自然に収まる。タブレット横置きで超えやすい | [R+]候補 1.4.8 |
| 禁則処理・約物の扱い | `line-break: strict`、`word-break: auto-phrase`（対応ブラウザ）、約物の詰めは `text-spacing-trim` | — | [G] JLReq |
| 見出しの大小と字送りで格を表す | 鳩月報の大見出しはこれを存分に | 見出しも実テキスト | [P]／[R] 1.4.5 |
| 明朝体の品 | 鳩月報の見出し・本文に使える | **本人用表示・レスキューカードの小〜中サイズでは、細い明朝の横画が飛ぶリスク**。太めのウエイト、またはゴシックを主に | [H]（要実機確認） |
| 朱・墨の二色刷り | 差し色として残す | 朱は背景との比を計算して使う。「墨」は真っ黒より少し温かい黒でも 7:1 は確保可能 | [P]／[R] 1.4.3 |
| 紙の質感（生成り・わら半紙の地色） | 地色に使ってよい | テクスチャ画像で文字の後ろをザラつかせない。地は平らに | [G] COGA 4.4.11 |

## 2. 両端揃えについて

- WCAG 1.4.8（AAA）は「両端揃えにしない」を挙げるが、主な理由は欧文の語間ムラ。
- 和文のベタ組みは本来、文字が正方形の枠に並ぶので、両端揃えでも字間の伸び縮みは小さい（禁則処理での調整分のみ）。
- → [H] 和文本文の両端揃えは、行末に約物が続かない短文なら問題になりにくい。ただし、ブラウザの両端揃えは和文組版の調整（JLReq の約物の詰めなど）を十分に再現しないことがあるので、**実機で字間のムラを見て決める**。本人用表示の短い項目は左揃えで十分。

## 3. 1.4.12（テキストの間隔）との両立

- 利用者が行間 1.5 倍・段落間 2 倍・字間 0.12 倍・語間 0.16 倍に広げても、文字が切れたり重なったりしないこと [R]。
- 活版的な「きっちり組んだ」レイアウトは高さ固定になりがち。**高さを固定しない**、`overflow: hidden` で文字を切らない、を守れば、組みの美しさと両立できる。

## 4. 書体の選び方（決め方の手順）

現状: 全画面 Zen Kaku Gothic New（400/500/700、Google Fonts）。本人画面は 500/700 中心で、細い字は使っていない。変更するときは以下の手順で。

1. 候補を本人用・家族用・レスキュー・月報ごとに 2〜3 書体ずつ挙げる [P]。
2. 本人の視距離・設置環境で、同じ文言（日付・名前・予定1件）を並べて表示する。
3. 「どれが読みやすいか」と聞くより、**読み上げてもらう／読み違えがあるか**を見る（例: 「8」と「6」、「ソ」と「ン」、「土」と「士」）[H]。
4. 好みの差しかないなら [P] として作り手が決めてよい。

## 5. 懐かしさを出せる場所・控える場所

| 画面 | 懐かしさ・活版らしさ | 理由 |
|---|---|---|
| 鳩月報 | **存分に**。スポーツ紙・瓦版の題字、太い大見出しの組み、罫、朱。活版の「格」と、スポーツ紙の「大げささ」の掛け合わせ | ゆったり眺める画面で、楽しさが目的そのもの（spec 7章） |
| 本人用表示 | **骨格に効かせる**。版面の秩序、罫で区切るまとまり、地色 | 何度も見返すので秩序がそのまま分かりやすさになる。装飾は控える |
| 家族用操作 | 控えめ。ブランドの一貫性程度 | 速さ優先。慣れたスマホの操作感を崩さない（[G] COGA 4.2.2） |
| レスキューカード | **出さない** | 焦っている家族と、初めて父を知る人が読む・聞く。装飾はノイズ（spec 5章） |
