# デモ動画 台本（v0.3・11/5）

v0.2 からの変更は、末尾の「v0.2からの変更」にまとめた。目標は2分50秒（上限3分）。

## 核となるメッセージ

> **忘れても、大丈夫。**

0:10 で話す「忘れることより、まわりの反応のほうがつらいんじゃないか」への答え。作った機能が、ぜんぶこの一言の方を向いている。

| 場面 | 「忘れても」でつなぐと |
| --- | --- |
| 本人の画面 | 何度忘れても、見ればいつも同じ場所に今日がある |
| 家族の知らせ | 家族がいなくても、どこにいて、いつ帰るかが分かる。忘れても、知らせは画面に残る |
| レスキューカード | もし迷っても、家族がすぐに必要な情報を出せる |
| 鳩月報 | 本人が忘れても、その月の日々は鳩が覚えていて、新聞にして残す（思い出を作る機能というより、家族の代わりに覚えておく機能） |

締めのことば「介護するすべての人に、ほんの少し、息をつく時間を届けたい。」にもつながる。忘れても大丈夫な家なら、家族は同じ質問のたびに答えたり、正したりしなくてよくなる。お父さんへの言葉と、介護する人への言葉が一本の線になる。

**通し方**：ナレーションを場面ごとに足すと3分を超えるので、**字幕で一行ずつ通し、声に出すのは 0:35 と 1:50 の鳩のセリフだけ**にする。字幕の「忘れても」の行は、場面の字幕の一番上に、同じ書き方（同じ位置・同じ大きさ）で出す。

**言い方の決めごと**：「大丈夫」は効果として言い切らない。「もう一度見れば大丈夫」のように、何をすれば大丈夫なのかを添える。鳩の連打のツッコミは未実装なので、軸の説明にも入れない。

**ルール**（公式アンバサダーのまとめ）
- 3分以内
- ナレーションは日本語
- 映すのはハッカソン期間中に作った機能・コード・実装だけ
- 締切は 11/8(日) 20:00
- 主役は実際に動く画面

**この台本の決めごと**
- 映すのは、実機で動いている機能だけ。未実装のもの（連打のツッコミ、家族の分のレスキューカードなど）は出さない
- 父は出演しない。データはデモ用の家「豆田家」（架空）を使い、画面に「デモ用データ（架空）」と出る状態で撮る
- 待ち時間を切ったところには「※時間を短縮しています」と字幕を入れる
- 合成音声の読み上げには、すべて字幕を付ける（最終審査は Discord のライブ上映なので、音が聞き取りにくくても伝わるように）
- 安心感や介護負担の軽減は、確かめた効果として語らない。「〜できるようにした」「〜を減らしたい」「〜を届けたい」と言う
- 鳩は一人称（ぼく・わたし）を使わない。アプリの読み上げと話し方をそろえる

**話す人**
- 🕊️：鳩（アプリの読み上げと同じ合成音声。運営から可と回答あり）。名前は「はとやま」
- 🎙️：葵依さん（収録室で録音）
- 📱：実機が出す音（チャイム・読み上げ）。ナレーションではない

**時間の目安**：ナレーションと読み上げで約640文字（v0.2 は約590文字）。1秒6文字で読むと約1分47秒。残りの約1分10秒が、操作・チャイム・鳴き声・画面を見る間と、締めの画面になる。**文字数だけでは決まらないので、撮影前に一度読みながら操作して、ストップウォッチで測る**（下の準備リスト）。
