# デモ動画 台本（下書き v0.1・11/4）

構成は葵依さんの第二案「くるっくーがある生活」を土台にした。目標は2分50秒（上限3分）。

**ルール**（公式アンバサダーのまとめ）
- 3分以内
- ナレーションは日本語
- 映すのはハッカソン期間中に作った機能・コード・実装だけ
- 締切は 11/8(日) 20:00
- 主役は実際に動く画面

**この台本の決めごと**
- 映すのは、実機で動いている機能だけ。未実装のもの（連打のツッコミなど）は出さない
- 父は出演しない。データはデモ用の家「豆田家」（架空）を使い、画面に「デモ用データ（架空）」と出る状態で撮る
- 待ち時間を切ったところには「※時間を短縮しています」と字幕を入れる
- 合成音声の読み上げには、すべて字幕を付ける

**話す人**
- 🕊️：鳩（アプリの読み上げと同じ合成音声）。合成音声のナレーションが認められるかは Discord で確認中。だめなら葵依さんが読む
- 🎙️：葵依さん（収録室で録音）
- 📱：実機が出す音（チャイム・読み上げ）。ナレーションではない

## 決めること（撮影の前に）

1. **動画に出る鳩の名前**：デモ用の家の鳩は「はとやま」。ナレーションの鳩も「はとやま」でそろえるか、デモ用の家の鳩を「ぽーちゃん」に変えるか
2. **鳩の一人称**：「ぼく」でよいか
3. **合成音声のナレーション**：Discord の返事しだい。だめなら 🕊️ の部分も 🎙️ で読む
4. **レスキューカードの顔写真**：架空の人物のイラストを用意する

## 撮影の前の準備リスト

- [ ] 豆田家の画面で「デモ用データ（架空）」が出ていること
- [ ] 豆田家のレスキューカードに顔のイラストと服の写真を登録する
- [ ] 豆田家の10月に、ひとこと・写真を数件入れて、鳩月報（10月号）を作り直す
- [ ] お知らせの音を決める（鳩時計か通知音）
- [ ] 撮る数分後に「夕ごはん」のお知らせが始まるよう、豆田家の予定の時刻を調整する（撮影後に戻す）
- [ ] 家族の知らせ（音あり）を、撮影前に一度ためす（まだ実機で確認していない）
- [ ] レスキューカードの共有画面を iPhone で一度ためす（まだ実機で確認していない）
- [ ] タブレットの音量・画面の明るさ・画面を点けたままにする設定
- [ ] 読み上げが録画で聞き取れるか、試し撮りで確認する
