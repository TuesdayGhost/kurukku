# デモ動画 台本（下書き v0.2・11/5）

v0.1（11/4）からの変更は、末尾の「v0.1からの変更」にまとめた。目標は2分50秒（上限3分）。

**ルール**（公式アンバサダーのまとめ）
- 3分以内
- ナレーションは日本語
- 映すのはハッカソン期間中に作った機能・コード・実装だけ
- 締切は 11/8(日) 20:00
- 主役は実際に動く画面

**この台本の決めごと**
- 映すのは、実機で動いている機能だけ。未実装のもの（連打のツッコミ、予定をタップして読み上げる案など）は出さない
- 父は出演しない。データはデモ用の家「豆田家」（架空）を使い、画面に「デモ用データ（架空）」と出る状態で撮る
- 待ち時間を切ったところには「※時間を短縮しています」と字幕を入れる
- 合成音声の読み上げには、すべて字幕を付ける（最終審査は Discord のライブ上映なので、音が聞き取りにくくても伝わるように）
- 安心感や介護負担の軽減は、確かめた効果として語らない。「〜できるようにした」「〜を減らしたい」と言う

**話す人**
- 🕊️：鳩（アプリの読み上げと同じ合成音声。運営から可と回答あり）。名前は「はとやま」
- 🎙️：葵依さん（収録室で録音）
- 📱：実機が出す音（チャイム・読み上げ）。ナレーションではない

## v0.1からの変更

- **冒頭**：「通知音→読み上げ→鳩の自己紹介」をやめ、実機の画面に重ねて「くるっくーは、〜電子伝書鳩です」と言い切る。最初の10秒で誰の・何のためのものかが伝わる。夕ごはんの通知は、0:35の知らせの場面で音と読み上げを見せるので省いた
- **家族からの知らせ**：いちばん覚えてほしい場面として、読み上げが終わるまでナレーションを重ねない
- **レスキューカード**：0:35でボタンを映しておき、1:15で「いつも一番上にあるこのボタン」と回収する（付け足しの機能ではなく、毎日使う画面にいつもあることを見せる）
- **鳩月報**：材料→紙面の前後を見せ、Claude がアプリの中で書いていることを示す
- **Claude とつくった**：自作Skillを、実際の変更（文字の大きさと情報量）とセットで見せる。Supabase の権限テストはナレーションから外した
- **表現**：「何度見ても、同じ答えです」→「何度でも、今日を確かめられます」（予定は更新されるため）。「数字は、記録から数えた本物だけです」→「数字は記録を集計し、Claude が見出しと記事にします」（架空データのデモで紛らわしくないように）
- **未確認事項**：家族の音付き通知と iPhone での共有は確認済みにした。合成音声は解決済み
- **鳩の名前**：はとやまのまま（「決めること」から外した）
