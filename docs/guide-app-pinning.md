# 父の部屋のタブレットを「くるっくー」だけにする（Androidのアプリ固定）

家族向けの手順です（spec 2章：父の部屋は表示専用＋Androidの「アプリ固定」）。

くるっくーの中では、父の部屋の端末から予定や設定は変えられません（データベースの権限で止めています）。
ただ、ホームボタンや戻るボタンで、くるっくーの外（ほかのアプリや設定）に出てしまうことはあります。**アプリ固定**を使うと、くるっくーの画面から外に出られなくなります。

> 画面の名前や場所は、端末やAndroidのバージョンによって少し違います。下は Android 14 の例です。見つからないときは、設定の上にある検索で「固定」と探してください。

## 1. アプリ固定をオンにする（最初の1回だけ）

1. **設定** を開く
2. **セキュリティとプライバシー** → **その他のセキュリティ設定**（または「詳細設定」）
3. **アプリの固定** を開いて **オン** にする
4. 「固定を解除する前にPINを要求する」（または「解除時にロック画面を表示」）も **オン** にする
   - 父が偶然、固定を外してしまわないようにするため

## 2. くるっくーを固定する

1. Chrome でくるっくーの表示画面を開き、ログインして、画面に一度さわる（音が鳴るようになる）
2. **最近使ったアプリ** の画面を出す（画面の下から上へゆっくりなぞって止める、または四角いボタン）
3. Chrome のカードの上にある **Chromeのアイコン** を押す
4. **固定** を押す

これで、ホームボタンや戻るボタンを押しても、くるっくーの画面のままになります。

## 3. 固定を外す（家族が設定を変えたいとき）

- **ジェスチャーナビゲーション**：画面の下から上へなぞって、そのまま指を止める
- **3つのボタン**：**戻る** と **最近使ったアプリ**（四角）を同時に長押しする

ロック画面が出たら、PIN（暗証番号）を入れると外れます。

## あわせて確かめること

- **画面が消えないこと**：くるっくーは画面を点けたままにしますが、念のため **設定 → ディスプレイ → 画面消灯** を長め（30分など）にしておく
- **音量**：お知らせの音と読み上げは、タブレット本体の音量で決まる。父の部屋で、うるさすぎず聞こえる大きさにする
- **充電**：つないだままにしておく
- **お知らせの音を止める**：鳴っている間に画面にさわるか、「音を止める」を押すと止まる（表示はそのまま残る）
- **端末のメニュー**：日付・時計のあたりを5秒長押しすると出る（音のテスト・ログアウト）

## 確認の状態

- この手順は、Android 14 の一般的な画面をもとに書いた。父の部屋のタブレット（Headwolf FPad3）での画面の名前は、**まだ確かめていない**
