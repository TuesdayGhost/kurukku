# ロゴとアイコン

**状態：候補（未決定）。** アイコンは **A-2（判子）**、ロゴは **A-2の判子＋線で組んだ「くるっくー」（B-1）** を、いちばん良い候補として仮にアプリへ入れてある。
葵依がClaudeと5案（アイコン3・ロゴ2）を作って比べ、「ロゴとしていいな」と思った候補。実装について話し合ってから決める予定だったが、話し合う前に作業してしまった（11/5）。採用するか、どこに使うかはこれから決める。不採用なら、下の「ファイル」を消し、ヘッダーを文字の「くるっくー」に戻す。

## ファイル

| ファイル | 使う場所 |
| --- | --- |
| `app/brand.js`（`LOGO`） | 家族の画面・ログイン画面のヘッダー。色は `currentColor`（CSSで `--accent`） |
| `app/icon.svg` | ブラウザのタブ（ファビコン） |
| `app/apple-touch-icon.png`（180px） | iPhone・iPad のホーム画面 |
| `app/icon-192.png`・`app/icon-512.png` | Android のホーム画面（`manifest.webmanifest`）。地は `--accent`、判子は `--bg` の色。判子は72%に縮め、丸く切り抜かれても欠けない |

本人の画面（通常・通知・夜）にはロゴを出さない。spec 1章「装飾が予定への注意を奪わない」ため。

ホーム画面に追加したときは、ブラウザ（Safari・Chrome）で開く（`manifest.webmanifest` の `display: "browser"`、11/5 決定）。
「アプリとして開く（standalone）」にすると、iPhoneではSafariとログインが別になり、レスキューカードの「元の写真を開く」（新しいタブ）が開かないおそれがあるため。Androidのアイコン長押しでレスキューカードへ行く近道（shortcuts）も、この設定では使えないので外した。

## 形の決め方

フォントや自由な曲線に頼らず、円・直線・円弧だけで組んだ。1色で成り立つ。

- 鳩：胴は円 C(124,146) r56、頭は円 C(172,86) r24。首は半径16の円を両方に外接させて円弧でつなぐ。尾は2点から胴の円への接線。くちばしは頭の円上の2点からの三角形。
- 判子：外円 r118 の塗りから、内側の輪（r102・線幅6）と鳩をマスクで抜く。翼のひと筋と目だけ塗りに戻す。
- 「くるっくー」：100単位の枠で、線のひらがなとして組んだ（線幅11）。「る」は横画→斜め→半径24の円弧→半径9の輪。
- 色：アプリの `--accent`（鳩の首の緑 #2f5d50）と `--bg`（#e9edf1）。

鳩・ロゴは審査対象外のため、ここで止める。B-2（「ー」を止まり木にして鳩がとまる案）は、鳩月報の題字や動画のタイトルに使う余地として残す。
