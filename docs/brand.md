# ロゴとアイコン

**11/5 決定（葵依）：採用。** アイコンは **A-2（判子）**、ロゴは **A-2の判子＋線で組んだ「くるっくー」（B-1）**。
葵依がClaudeと5案（アイコン3・ロゴ2）を作って比べた候補を、別のClaudeが話し合いの前に仮に実装した。実際の画面を見たうえで、同日に採用を決めた。

**使う場所（11/5 決定）**
- ブラウザのタブ（ファビコン）、ホーム画面のアイコン、家族とログイン画面のヘッダー（実装済み）
- デモ動画の冒頭のタイトルと最後の締め。タグライン「家族の知らせと日々を届ける鳩」を添える
- 鳩月報の題字に **B-2**（「ー」を止まり木にして鳩がとまる案）
- 本人の画面（通常・通知・夜）には出さない

**キャラクターの鳩（11/5 決定）**：判子の鳩1羽にそろえる。父の部屋の右下のボタン、鳩月報の「つつかれた」のタイル、題字の鳩（`app/brand.js` の `pigeon()` と `WORDMARK_PERCH`）。機能を表すアイコン（ごはん・バス・手紙など）は Lucide の線画のまま。絵文字🕊️は使わない。右下のボタンの鳩だけは、画面の内側を向くよう左右を反転する（11/5 葵依：外を向いていた）。
**家と鳩（線の鳩）**：葵依が作った別案。家の屋根の中の鳩で「家に帰ってくる伝書鳩」。小さいと読みにくく、右下のボタンでは「ホームに戻る」に見えるおそれがあるため、アプリの中では使わず、**デモ動画のタイトル画面**に使う（11/5 決定）。

## ファイル

| ファイル | 使う場所 |
| --- | --- |
| `app/brand.js`（`LOGO`） | 家族の画面・ログイン画面のヘッダー。色は `currentColor`（CSSで `--accent`） |
| `app/icon.svg` | ブラウザのタブ（ファビコン） |
| `app/apple-touch-icon.png`（180px） | iPhone・iPad のホーム画面 |
| `app/icon-192.png`・`app/icon-512.png` | Android のホーム画面（`manifest.webmanifest`）。地は `--accent`、判子は `--bg` の色。判子は72%に縮め、丸く切り抜かれても欠けない |

本人の画面（通常・通知・夜）にはロゴを出さない。spec 1章「装飾が予定への注意を奪わない」ため。

ホーム画面に追加したときは、ブラウザ（Safari・Chrome）で開く（`manifest.webmanifest` の `display: "browser"`、11/5 決定）。
「アプリとして開く（standalone）」にすると、iPhoneではSafariとログインが別になり、レスキューカードの「元の写真を開く」（新しいタブ）が開かないおそれがあるため。Androidのアイコン長押しでレスキューカードへ行く近道（shortcuts）も、この設定では使えないので外した。

## 形の決め方

フォントや自由な曲線に頼らず、円・直線・円弧だけで組んだ。1色で成り立つ。

- 鳩：胴は円 C(124,146) r56、頭は円 C(172,86) r24。首は半径16の円を両方に外接させて円弧でつなぐ。尾は2点から胴の円への接線。くちばしは頭の円上の2点からの三角形。
- 判子：外円 r118 の塗りから、内側の輪（r102・線幅6）と鳩をマスクで抜く。翼のひと筋と目だけ塗りに戻す。
- 「くるっくー」：100単位の枠で、線のひらがなとして組んだ（線幅11）。「る」は横画→斜め→半径24の円弧→半径9の輪。
- 色：アプリの `--accent`（鳩の首の緑 #2f5d50）と `--bg`（#e9edf1）。

鳩・ロゴは審査対象外のため、形の作り込みはここで止める。


## 大事なことば（11/5 葵依）

> **5 minutes to breathe**
> 介護するすべての人に、ほんの少し、息をつく時間を届けたい。

（11/5 に「介護するすべての人に、ほんの少し、息をつく時間を届けたい。」から変更。「届けたい」は鳩が届けるものにかけている）

葵依が自分自身に送る言葉でもある。くるっくーが目指すこと（同じ質問に答える回数や、ホワイトボードを書き直す手間を減らして、介護する人に息をつく時間を）を表す。効果を確かめた言葉ではなく、願いとして使う。
- 使う場所：デモ動画の最後の締め（`docs/demo/ending-breathe.png`）。ほかの場所にも入れてよい

## 葵依のことば（11/6。提出の概要・動画の冒頭と締めの候補。原文のまま）

> 僕は毎朝、ホワイトボードに家族のその日の予定を書いています。天気予報を調べ、家族の予定を聞いて、書き出す。フルタイムで働く僕にとって、これは小さくない負担でした。認知症の家族がいれば、予想外のことも起きます。そのたびに、僕の時間は少しずつ削られていきます。
> そんな暮らしの中にも、ほんの少し息をつける時間が持てるように、このアプリを作りました。
>
> 僕のアプリは、決して華やかなものではありません。
> 目指したのは、日々忘れていく父が、その瞬間を穏やかに過ごせるように、ほんの少しだけ支える道具です。
> 忘れても大丈夫だと思えること。そんな、優しいテクノロジーを目指しました。

- 使いどころ（11/6 決定）：前半は動画 0:10「いつもの朝」の🎙️（N2 に差し替え済み）。後半の最後の一文は締めの画面の一言（N8）。「華やかなものではありません…支える道具です。」は提出フォームの「概要」に使う。
- 「息をつける時間が持てるように」「目指しました」は願いの言い方なので、効果を確かめたと言わない方針（README・台本）と合っている。
