# お知らせの音のファイル

表示端末でお知らせが始まるときに鳴らす音です。家族の「家と端末」→「お知らせの音」で選びます。

| ファイル名 | 音 | 状態 |
| --- | --- | --- |
| （ファイルなし） | 通知音（ピン・ポーン） | ブラウザで合成 |
| `pigeon_clock.mp3` | 鳩時計（ポッ・ポー） | 準備中 |
| `pendulum.mp3` | 振り子時計（ボーン、いつも1回） | 準備中 |

ファイルを置くと、そのまま選べるようになります（ない間は「音の準備中」で選べません）。

- 形式：mp3（またはブラウザで再生できる音声ファイル）。2秒くらいまで
- 置く音の出典・作った人・利用条件・クレジットを、この表の下に必ず書く
- 公開リポジトリに置いてよい（再配布してよい）音だけを置く
