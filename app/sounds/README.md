# お知らせの音のファイル

表示端末でお知らせが始まるときに鳴らす音です。家族の「家と端末」→「お知らせの音」で選びます。

| ファイル名 | 音 | 状態 |
| --- | --- | --- |
| （ファイルなし） | 通知音（ピン・ポーン） | ブラウザで合成。2回鳴らす |
| `pigeon_clock.wav` | 鳩時計（ポッ・ポー×2が入っている） | 1回再生 |
| `pendulum.wav` | 振り子時計（ボーン） | 時刻と取り違えないよう、いつも1回 |

ファイルを置くと、そのまま選べるようになります（ない間は「音の準備中」で選べません）。

- 形式：wav / mp3 など、ブラウザで再生できる音声ファイル
- 置く音の出典・作った人・利用条件・クレジットを、この表の下に必ず書く
- 公開リポジトリに置いてよい（再配布してよい）音だけを置く

## 出典・クレジット

- `pigeon_clock.wav`（元のファイル名 `01_cuckoo_wood.wav`、3.4秒）、`pendulum.wav`（元のファイル名 `06_coil_gong_single.wav`、6.2秒）
